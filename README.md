## 🚀 Featured Project

### Linux Server Health Monitor & Automated System Report

A Bash-based Linux monitoring tool that automatically checks the health of a Linux system and generates a detailed system report.

**Key features:**
- CPU, RAM, and disk monitoring
- OK / WARNING / CRITICAL health thresholds
- SSH and service availability checks
- Timestamped system logs
- Automated execution using Cron
- Exit codes for automation
- Overall system health calculation

**Technologies:**

`Linux` `Bash` `Cron` `WSL2` `Shell Scripting` `Automation`
