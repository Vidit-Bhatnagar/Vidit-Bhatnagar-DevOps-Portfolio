Linux Server Health Monitor

A Bash-based Linux server monitoring tool that checks CPU, RAM, and disk usage, validates SSH and Cron service status, calculates overall system health, and generates timestamped daily reports with alert logging for WARNING/CRITICAL conditions.

Automation: Runs automatically via Cron every 5 minutes, with execution verified through journalctl and exit codes (0 = OK, 1 = WARNING, 2 = CRITICAL) mapped to system health state.
